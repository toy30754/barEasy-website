Bar Easy Taichung｜網站使用說明
完成日期：2026-09-17

一、先在自己的電腦看看
將 website.zip 完整解壓縮，再用 Chrome 或 Edge 開啟 index.html。
請保留 index.html、styles.css、script.js 及 assets 資料夾的相對位置。
這一版是純靜態網站，圖片與程式全部隨檔附上，不需要安裝軟體、輸入指令、資料庫或 API 金鑰。

二、放到 Cloudflare，讓其他人也能連線
1. 登入 https://dash.cloudflare.com/。
2. 找到 Workers & Pages，按 Create application，進入 Pages 的建立入口。
3. 選擇 Use direct upload 或 Get started → Drag and drop your files，實際名稱依介面版本而定。
4. 輸入專案名稱，例如 bareasy-taichung，再將 website.zip 拖進上傳區。
5. 按 Deploy site／Save and Deploy。
6. 完成後，使用後台提供的 pages.dev 網址查看網站。
ZIP 最外層已放好 index.html，可直接上傳，不用另外建置。
官網說明：https://developers.cloudflare.com/pages/get-started/direct-upload/

這次只交付網站檔案，尚未登入或修改你的 Cloudflare、GitHub 或網域設定。
如果日後使用自己的網域，請在這個 Pages 專案內選 Custom domains → Set up a domain，依 Cloudflare 畫面完成。
請使用 Bar Easy 自己的網域；這一版沒有預設沿用前一個牛排網站的 hiSteak.com。

三、之後要更新網站
在同一個 Pages 專案選 Create a new deployment，再上傳整個更新後的網站。
若日後打算讓 GitHub 修改後自動發布，請從一開始選擇 Git 整合，或另建 Git 整合專案。直接上傳專案不能原地切換為 Git 整合。

四、修改內容與圖片
index.html：店名、介紹文案、地址、電話、Instagram 與地圖連結。
styles.css：網站色系、字體、版面與手機版。
script.js：手機選單、捲動導覽、進場效果。
assets/interior-hero.jpg：首頁店內全景。
assets/lounge.jpg：沙發與店內細節。
assets/cocktails.jpg：調酒與佐酒餐點。

換圖時，把自己的 JPG 照片存成同一個檔名後覆蓋，再將整個網站重新上傳。
首頁建議用寬幅橫向照片，其餘兩張使用正方形照片即可。請真正匯出 JPG，不能只修改副檔名。
三張現有照片都是實際店家照片，來源與權利說明另見「照片來源.txt」。
